# 云服务器工作台

桌面组件展示服务器状态、CPU、内存、磁盘和最近采集时间。「打开控制台」可查看历史、服务详情，并按需唤醒已配置的 Instabox。

组件 0.1.5 需要支持服务器管理的 SoulDesk 0.5.11 或更高版本。

初次安装时，在控制台的「服务器清单」添加 Linux SSH 或 Instabox 服务器，也可导入从控制台导出的 JSON。可编辑、移除或通过拖动手柄及上下键排序，排序同步到桌面组件。移除只影响本机清单。

默认导出完整备份，包含服务器连接配置、顺序、服务设置、SSH 私钥与主机信任、Instabox API 密钥及采集设置。通过 SoulDesk 原生对话框选择本地 JSON 文件，备份含明文凭据，请妥善保管。

导入合并至清单并跳过重复目标。原备份中已配齐凭据的服务器导入后进入采集。历史采样保存在各自的宿主数据库中。

配置及凭据由 SoulDesk 使用 Windows 当前用户加密保存，组件包仅包含通用代码和界面资源。宿主内置采集可沿用旧组件的迁移数据。关闭或隐藏组件只影响显示，删除最后一个实例或退出 SoulDesk 后停止调度。
