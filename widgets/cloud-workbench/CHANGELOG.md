# 版本记录

## 0.1.5

- 服务器排序时拖动行跟随指针，其余行平滑让位。松手后落到新位置，取消时回到原位。

## 0.1.4

- 修复 Windows 控制台中按住服务器手柄拖动时顺序无法保存的问题。

## 0.1.3

- 服务器清单支持添加、编辑、移除、拖动和键盘排序。
- 支持包含配置和凭据的完整 JSON 备份。导入合并时跳过重复目标。
- 新安装从空清单开始，界面按实际配置显示服务器数量和类型。

## 0.1.2

- 采集改由 SoulDesk 内置后台负责。配置、凭据和历史支持一次性迁移到本机宿主。
- 控制台在 SoulDesk 内打开，沿用原工作台的指标趋势、服务检查与手动唤醒。

## 0.1.1

- SoulDesk 调度单轮采集，日常查看状态可只运行宿主。
- 增加首次连接工作台的入口。详情、历史与唤醒操作通过按需打开的临时控制台处理。

## 0.1.0

- 新增桌面紧凑总览，显示本机工作台的服务器状态、资源使用率和最近采集时间。
- 区分暂停、冷却、数据过期和采集失败，提供浏览器控制台入口。
