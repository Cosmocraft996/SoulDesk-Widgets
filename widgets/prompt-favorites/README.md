# Prompt 收藏夹

新增、编辑、搜索和复制本机提示词收藏。

- 通过「新建分类」添加分组。拖动分类右侧的手柄排序时，各组临时折叠，标题随拖动让位，松手或取消后恢复原来的展开状态。右键也可将分类移至自定义分类的顶部或底部。右上角的同一个按钮可全部展开或折叠。
- 新增或编辑收藏时可选择分类。组内拖动或使用右键菜单的顶部和底部操作可调整组内顺序。拖出当前组后可放到其他分类标题上，也可用右键菜单的「移动到分组」。新加入的收藏显示在目标组顶部。
- 「未分类」固定在底部。旧版收藏会显示在该组，删除分类也会将组内收藏移回该组。

组件 ID `local.souldesk.prompt-favorites`。宿主通过清单声明的能力提供服务。
