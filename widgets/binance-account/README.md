# 币安账户监控

需要实现 `binance.account.read` 和 `binance.account.trade` 的 SoulDesk 宿主。通过宿主「设置 → 网络与数据 → 币安账户监控」配置 HMAC 凭据，保存后先测试读取。在宿主核对并授权当前组件包的 SHA-256，新的摘要需要重新授权。授权交易需在该位置单独启用。桌面和详情显示当前选中账户，完整记录保留币安响应字段和原单位。

简洁卡片显示八项仓位指标，金额折成 USDT，回报率及保证金比率保留百分比。找不到可靠的数值或折算价时显示「—」。最优价平仓按对手盘第一档计算限价，并使用 IOC。未成交部分由币安撤销，界面以实际回执更新仓位。普通下单、撤单、改单和合约设置在详情窗发起。交易超时后可查单，仍无法确认时到宿主设置核对并归档解锁，宿主不会自动补发。

在广场根目录运行 `python scripts/widget.py binance-account` 生成安装包和 SHA-256。配置、验收、安装和发布分别按宿主及组件广场工作流处理。
