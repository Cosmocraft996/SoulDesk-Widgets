# 币安行情与价格警报

查看币安现货与 USDT 永续公开行情，并在本机配置价格警报。

- 列表和网格可切换，默认列表。主组件提供小、中、大三档尺寸。标的支持搜索、别名、替换、移出和拖动排序。
- 主面板的报价颜色和箭头比较约一分钟前的成交价，样本不足时显示中性色。小图默认 4 小时，同时显示区间涨跌、滚动 24 小时涨跌和有效警报线。
- 点击走势图打开独立 K 线窗口，默认显示 1 小时 K 线。底部时间轴和右侧价格轴分别用滚轮缩放，拖动绘图区可横向平移、上下移动价格画面，也可在最新 K 线右侧留白。接近历史边缘时自动加载更早的数据，点击「回到最新」恢复默认缩放和自动价格范围。
- K 线支持选价、均线周期设置、布林带、成交量及永续未平仓量。永续可切换成交价和标记价。悬停蜡烛显示开、高、低、收和涨跌幅，拖动右侧警报标签可直接保存新价位。
- 价格警报使用当前所选价格来源。到价的方向由警报价与现价决定。配套宿主在冷却结束后收到仍满足条件的新鲜报价会再次提醒，断线恢复后也用新鲜报价判断。穿越方向可手动选择，首笔和重连后的首笔有效报价建立基准，触及或跨过警报线时提醒。
- 每条规则可选 Windows 通知或灵动通知，点击通知打开对应市场和价格来源的 K 线。行情铃声通过宿主「应用设置 → 通知」统一开关。有效规则由宿主持续处理，移出自选后仍可从「全部警报」管理。穿越与两种通知入口依赖配套宿主。
- K 线的新警报默认重复提醒、使用灵动通知，重复到价的默认冷却为 5 秒。调整选项会自动保存，名称、价位和冷却时间在结束输入或按回车后保存。上方／下方入口在首次有效修改后创建，图上选价入口直接创建。
- 「触发历史」可手动清空，也可设置是否自动清理和保留天数。默认保留最近 3 天，设置对该宿主上的所有行情实例生效。清理入口需配套宿主，旧宿主可继续查看触发历史。

组件 ID `local.souldesk.market`。0.3.0 起需要支持 `market.chart` 的宿主，旧版自选、规则及历史可随组件升级读取。
