# 汇率换算

新实例依次显示人民币、美元、日元。用「＋」添加可用币种，用行尾「×」移除。币种列表超出显示区域时可滚动查看。组件铺满窗口，字号、行高和间距随窗口尺寸调整。编辑任意一行金额会更新其他行，结果按四舍五入固定显示两位小数。已有实例保留原币种顺序和主题。

币种选项取自 Frankfurter 当前目录中提供参考汇率的货币。组件展示所选币种最早的数据日期，将鼠标移到币种上可查看对应日期。打开组件后取数，按 30 分钟间隔自动检查，也可手动刷新。刷新失败时仍可用本次打开期间上次成功的汇率。

组件 ID 为 `local.souldesk.widgetjs.forex`。自 0.1.4 起需要支持 `content.get` 的 `forex-rates` 来源的宿主。

数据来源：[Frankfurter 公开参考汇率](https://frankfurter.dev/)。
